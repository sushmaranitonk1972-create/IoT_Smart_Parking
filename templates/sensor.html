💡 How IoT Sensor Works

1. Sensor detects the vehicle.
2. Sensor measures the distance.
3. Sensor sends data to Flask.
4. Flask updates the MySQL database.
5. Parking slot status becomes Occupied or Available.
6. Dashboard displays the updated status.
